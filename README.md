# LDK Node bindings

Reproducible Swift, Kotlin JVM, Kotlin Android, and Python distributions of
[LDK Node](https://github.com/lightningdevkit/ldk-node).

Native source and the authoritative UniFFI interface remain in LDK Node. This
repository owns pinned release inputs, packaging, CI candidates, independent
verification, and locally authorized publication. The selected native source
and toolchain are recorded in the release inputs.
